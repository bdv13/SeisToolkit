# SeisToolkit
Python tools for SEG-Y inspection, headers and seismic processing

Tools:

- SEG-Y I/O
- SEG-Y files information table
- Resort traces
- Trace Length
- Extract geometry / export survey tracklines (*csv, *gpkg)
- Automatic SEG-Y parts finder
- Combine several SEG-Y files in one dataset

version 0.2 (2026/06/24)
